# Продукт: proxy-for-ubuntu

Существующий Rust/Tauri-продукт: системный прокси для Ubuntu (Tauri GUI,
демон, CLI; общий крейт `pfu`). Репозиторий уже лежит в каталоге прогона —
это настоящий клон с историей `.git`; работай с ним, а не создавай новый
продукт в `product/`.

# Что нужно изменить

Сейчас `Config::parse` отклоняет синтаксически неверные правила, ссылки на
неизвестный outbound и дубли имён outbound, но молча принимает два класса
бесполезных правил:

1. точные дубли одного и того же правила;
2. правила после терминального `MATCH` — они никогда не сработают.

Добавь в библиотеку `pfu` предупреждения о качестве таблицы правил:

- `Config::warnings() -> Vec<ConfigWarning>`, где `ConfigWarning` содержит
  номер правила (`rule`, 1-based), стабильный код (`code`) и текст (`message`);
- коды: `W_RULE_DUPLICATE` для точного дубля (совпадает тип, аргументы и
  действие, регистр типа и значения не различает);
- `W_RULE_UNREACHABLE` для правила, стоящего после первого `MATCH`;
- порядок предупреждений — по возрастанию `rule`, без дублей одного правила;
- предупреждения не делают конфиг невалидным: `parse`/`validate` работают
  как раньше, `warnings()` — отдельный проход.

Публичный API и тесты — в `app/src-tauri/src/config.rs`. Существующие
218 unit-тестов должны остаться зелёными; новые тесты обязаны покрывать оба
кода и порядок. Никаких новых зависимостей и сетевых установок.
