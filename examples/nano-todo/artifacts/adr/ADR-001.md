# ADR-001: JSON-файл вместо БД

## Контекст
Нужен минимальный todo CLI без зависимостей. Связанные `REQ`: `REQ-001`, `REQ-002`, `REQ-003`.

## Решение
Хранить задачи в одном JSON-файле рядом с приложением. Обоснование по принципу Ponytail: меньше кода и нет сервера.

## Последствия
- Положительные: ноль зависимостей
- Отрицательные: нет конкурентного доступа
- Отвергнуто: SQLite
