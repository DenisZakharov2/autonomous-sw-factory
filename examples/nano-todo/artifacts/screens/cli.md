# Спецификация экрана CLI

## Назначение
Терминальный интерфейс для трёх команд.

## Состояния
- Empty: `No tasks`
- Loading: не применимо
- Populated: строки задач
- Error: сообщение об ошибке
- Partial/Offline: не применимо

## Доступность
- Клавиатура: да
- Контраст: терминал
- Фокус: не применимо
