# Todo CLI

## 1. Что это
Минимальный список задач в терминале. Только стандартная библиотека Python.

## 2. Запуск
```bash
python3 product/src/todo.py add "купить хлеб"
python3 product/src/todo.py list
```
Требования: Python 3.10+.

## 3. Проверка
```bash
python3 -m unittest discover -s product/tests
```
Ожидаемый результат: `OK`.
