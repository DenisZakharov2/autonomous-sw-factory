# Руководство пользователя

## 1. Начало
Откройте терминал в папке продукта.

## 2. Основные действия
1. `add "текст"` — добавить задачу.
2. `list` — показать задачи.
3. `done 1` — отметить выполненной.

## 3. Ошибки
| Симптом | Причина | Что делать |
| :--- | :--- | :--- |
| `no task 1` | неверный id | `list` и повторить |
