# Установочный бриф проекта

## 1. Цель (JTBD)
Разработчик хочет вести список задач в терминале без внешних зависимостей и без веб-интерфейса.

## 2. Out-of-Scope
- Веб-интерфейс
- Синхронизация между устройствами
- Пользовательские аккаунты

## 3. Требования
| Код | Описание | Приоритет |
| :--- | :--- | :--- |
| `REQ-001` | Добавить задачу | `Must-Have` |
| `REQ-002` | Показать список задач | `Must-Have` |
| `REQ-003` | Отметить задачу выполненной | `Must-Have` |

## 4. Профиль
- `customer_profile`: `DEVELOPER`
- Язык документации: русский
- Ограничение: только стандартная библиотека Python
