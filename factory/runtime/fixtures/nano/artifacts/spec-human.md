# Понятное ТЗ для человека

## 1. Что делает система
`REQ-001` — добавляет задачу. `REQ-002` — показывает список. `REQ-003` — отмечает задачу выполненной.

## 2. Как проверяем
| ID | Что проверяем | Как проверяем |
| :--- | :--- | :--- |
| `REQ-001` | добавление | запустить `add` и `list` |
| `REQ-002` | список | запустить `list` |
| `REQ-003` | завершение | запустить `done 1` и `list` |
