# Инженерная спецификация

## 1. Требования
| ID | Требование | Приоритет | Источник |
| :--- | :--- | :--- | :--- |
| `REQ-001` | `todo add <text>` добавляет задачу | `Must-Have` | интервью |
| `REQ-002` | `todo list` печатает задачи | `Must-Have` | интервью |
| `REQ-003` | `todo done <id>` меняет статус | `Must-Have` | интервью |

## 2. Приёмка
| ID | Given | When | Then |
| :--- | :--- | :--- | :--- |
| `REQ-001` | пустой файл | `add "купить хлеб"` | задача с id 1 |
| `REQ-002` | одна задача | `list` | строка с задачей |
| `REQ-003` | задача id 1 | `done 1` | статус done |
